## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/RasanjaliHerath/rasanjaliherath.github.io.git
```

Navigate to the project directory:

```bash
cd rasanjaliherath.github.io
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
